# Security

Report suspected vulnerabilities privately to [nfangxu@gmail.com](mailto:nfangxu@gmail.com). Include the affected repository, commit and a minimal reproduction. Never include credentials, sessions, private documents or production data in public issues.

This site serves public static content only. It has no login, user database, application gateway or connection to a user's Orchpact admin API. Technical source snapshots are explicitly pinned, and builds must not read private runtime files or download a moving main branch.

For runtime, authorization, billing or file-delivery issues in the engine, see the [main repository security policy](https://github.com/orchpact/orchpact/blob/main/SECURITY.md).
